# CARVISTA AI

Streamlit used-car price prediction app with a protected admin dashboard.

## Features
- User signup and login
- Car price prediction
- AI analysis and market dashboard
- Personal prediction history
- Admin login
- Visitor-session counts, registered-user list, successful login history, all predictions, and page views
- SQLite storage in `carvista.db`

## Setup
See `ADMIN_SETUP.txt` for administrator configuration.

Keep your existing `carvista.db`, `final_data.csv`, and `model.pkl` in the same folder as `app.py`.
